sidebar:
  order: 3
---

```tsx
<ThinkingOrb
  state="working"
  size={64}
  theme="auto"
  speed={1}
  paused={false}
/>
```

| Prop | Type | Default |
| --- | --- | --- |
| `state` | Orb state | `working` |
| `size` | `20 \| 64` | `64` |
| `theme` | `auto \| light \| dark` | `auto` |
| `speed` | `number` | `1` |
| `paused` | `boolean` | `false` |
| `accessibilityLabel` | `string` | Per-state label |
| `testID` | `string` | — |
