`@mhaadi/thinking-orbs-native` provides nine monochrome indicators for agent
work, search, listening, composing, connection, and other in-progress states.

## Install

```bash
pnpm add @mhaadi/thinking-orbs-native
pnpm add @shopify/react-native-skia react-native-reanimated react-native-worklets
```

## Use an orb

```tsx
import { ThinkingOrb } from '@mhaadi/thinking-orbs-native';

<ThinkingOrb state="searching" size={20} />
```

The renderer uses React Native Skia for drawing and Reanimated for its UI-thread
clock. It supports 20px and 64px density profiles, reduced motion, pausing, and
light or dark presentation.
