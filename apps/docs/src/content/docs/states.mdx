---

| State | Meaning |
| --- | --- |
| `working` | General work in flight |
| `searching` | Looking something up |
| `solving` | Working through a problem |
| `listening` | Receiving input |
| `connecting` | Opening or checking a connection |
| `weaving` | Combining sources or ideas |
| `composing` | Writing a response |
| `breathing` | Quiet, neutral thinking |
| `shaping` | Forming a structure |

Use the state as information, not decoration. A `searching` orb over a local
calculation communicates the wrong activity.
